# Day 1 — Microsoft 365 and Entra ID Fundamentals

## 1. Objective

Understand the purpose of Microsoft 365 and Microsoft Entra ID, identify key cloud services, and explain the difference between authentication and authorization.

## 2. What I learned

### Microsoft 365

Microsoft 365 is a collection of productivity, collaboration, and administration services used by organizations.

- **Exchange Online:** Hosted email and calendars.
- **Microsoft Teams:** Chat, meetings, and collaboration.
- **OneDrive:** Individual work-file storage and synchronization.
- **SharePoint Online:** Team sites and shared organizational content.
- **Microsoft Entra ID:** Identity and access management.
- **Microsoft Intune:** Device and application management.

### Microsoft Entra ID

Microsoft Entra ID is Microsoft's cloud identity and access management service.

Key concepts:

- **User:** A digital identity representing a person or account.
- **Group:** A way to organize identities and manage access where supported.
- **Authentication:** Verifying identity.
- **Authorization:** Determining permitted access and actions.
- **Tenant:** An organization's dedicated Microsoft cloud directory and configuration.

## 3. Real-world scenario

**Problem:** An employee cannot sign in to Microsoft 365.

Troubleshooting approach:

1. Confirm the affected application and exact error.
2. Verify the account status and username.
3. Investigate authentication, MFA, and applicable access policies.
4. Review available sign-in logs and failure details.
5. Apply an authorized fix, verify the result, and document the ticket.
